# Stopwatch Web Application

## About the Project
A simple and responsive online stopwatch application built using HTML, CSS, and JavaScript.

## Features
- Start Stopwatch
- Pause Stopwatch
- Resume Stopwatch
- Reset Stopwatch
- Record Lap Times
- Mobile Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript
